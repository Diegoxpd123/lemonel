# Lemonel

Landing de Lemonel, joyería y accesorios de regalo en Perú. Hecha con Astro y GSAP.

## Desarrollo

```
npm install
npm run dev
```

## Datos de muestra

Productos, precios y descuentos por volumen: `src/data/products.ts` y `src/data/config.ts`.
El número de WhatsApp (`config.whatsapp`) es un valor de prueba.

## Fotos

Las fotos son de Pexels y sirven como referencia. Los enlaces de origen están en `public/fotos-creditos.json`.
